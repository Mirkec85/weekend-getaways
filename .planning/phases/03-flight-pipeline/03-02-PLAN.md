  <action>
**File 1: `pipeline/selector.ts`**

1. Import `TequilaFlight` type from `./fetcher` (type-only import is fine).

2. Export **`Deal` interface**:
   - `destination_iata: string` — from `TequilaFlight.flyTo`
   - `destination_name: string` — from `TequilaFlight.cityTo`
   - `price_eur: number` — from `TequilaFlight.price`
   - `depart_at: string` — from `TequilaFlight.local_departure` (ISO timestamp)
   - `return_at: string` — from `TequilaFlight.route[route.length - 1].local_departure` (last leg departure = return journey start)
   - `booking_url: string` — from `TequilaFlight.deep_link`

3. Export **`selectTopDeals(flights: TequilaFlight[], count = 3): Deal[]`**:
   - Defensively re-sort by `price` ascending (API claims to sort but don't trust it)
   - Iterate sorted flights, skip if `flyTo` already seen (deduplicate by destination IATA)
   - For each selected flight, map to `Deal`:
     - `return_at`: use `f.route[f.route.length - 1]?.local_departure ?? f.local_arrival` (defensive fallback if route is unexpected)
   - Stop when `selected.length >= count`
   - Return the selected array (may be < count if fewer unique destinations exist — this is correct behavior, NOT an error)

**File 2: `pipeline/enricher.ts`**

1. Import the `Deal` type from `./selector`.

2. Export **`EnrichedDeal` type** — extends `Deal` with `hotel_estimate_eur: number | null`.

   NOTE: This is the SAME `EnrichedDeal` type that `cache.ts` (Plan 01) also declares. The orchestrator (Plan 03) will resolve this — for now, define it here as the canonical source and Plan 03 will update `cache.ts` to import from here instead of declaring its own.

3. Export **`enrichWithHotelEstimate(deals: Deal[]): EnrichedDeal[]`**:
   - Load the hotel estimates JSON: `const estimates: Record<string, number> = require('../../data/hotel-estimates.json')`
   - Use `require()` (not ES import) because `pipeline/tsconfig.json` is CommonJS and JSON imports need `resolveJsonModule` which may not be configured
   - Map each deal: spread `...deal`, add `hotel_estimate_eur: estimates[deal.destination_iata] ?? 80`
   - The fallback value of `80` EUR/night is the default for destinations not in the lookup file

CRITICAL: `return_at` must use the LAST route leg's `local_departure`, not the top-level `local_arrival` (which is the outbound arrival).
