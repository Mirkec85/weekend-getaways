<task type="auto">
  <name>Task 1: Create flight fetcher module (pipeline/fetcher.ts)</name>
  <files>pipeline/fetcher.ts</files>
  <action>
Create `pipeline/fetcher.ts` with these exports:

1. **`TequilaFlight` interface** — typed shape of a Tequila v2/search result item:
   - `id: string`, `price: number`, `cityTo: string`, `cityCodeTo: string`, `flyTo: string`
   - `countryTo: { name: string; code: string }`
   - `local_departure: string`, `local_arrival: string`, `deep_link: string`
   - `route: Array<{ flyFrom: string; flyTo: string; cityFrom: string; cityTo: string; local_departure: string; local_arrival: string }>`

2. **`TequilaResponse` interface** — `{ data: TequilaFlight[]; _results: number }`

3. **`getWeekendWindow(thursday?: Date)` function** — computes the next Friday (thursday + 1 day) and Sunday (thursday + 3 days), returns `{ date_from, date_to, return_from, return_to }` all formatted as `dd/MM/yyyy` using `date-fns` `format()` and `addDays()`. Both `date_from === date_to` (pin to single Friday) and `return_from === return_to` (pin to single Sunday).

4. **`fetchWeekendFlights(apiKey: string, today?: Date)` function** — builds query with `URLSearchParams`:
   - `fly_from: 'ZAG'`, `flight_type: 'round'`, `nights_in_dst_from: '2'`, `nights_in_dst_to: '3'`
   - `curr: 'EUR'`, `sort: 'price'`, `asc: '1'`, `limit: '20'`, `max_stopovers: '2'`
   - Date params from `getWeekendWindow(today)`
   - Calls `https://tequila-api.kiwi.com/v2/search?${params}` with header `{ apikey: apiKey }`
   - On non-ok response: throw `Error('Tequila API error: ${res.status} ${res.statusText}')`
   - Parse response as `TequilaResponse`, return `json.data ?? []`

Import `addDays` and `format` from `date-fns`. Do NOT use `@/` path aliases. The optional `today` parameter enables testing without mocking Date.

CRITICAL: Use `dd/MM/yyyy` format (NOT `yyyy-MM-dd`). The Tequila API requires DD/MM/YYYY.
CRITICAL: Both `return_from` and `return_to` MUST be provided when `flight_type=round`.
  </action>
  <verify>
Run `npx ts-node --project pipeline/tsconfig.json -e "import { getWeekendWindow } from './pipeline/fetcher'; console.log(getWeekendWindow(new Date('2026-02-26')))"` and confirm output shows `date_from: '27/02/2026'`, `return_from: '01/03/2026'` (Friday and Sunday respectively, DD/MM/YYYY format).
  </verify>
  <done>
`pipeline/fetcher.ts` exports `TequilaFlight`, `TequilaResponse`, `getWeekendWindow`, and `fetchWeekendFlights`. The weekend window computation produces correct DD/MM/YYYY dates for the Friday after a given Thursday and the following Sunday. The fetch call uses the `apikey` header (not query param) and returns `data ?? []`.
  </done>

<task type="auto">
  <name>Task 2: Create cache layer module (pipeline/cache.ts)</name>
  <files>pipeline/cache.ts</files>
  <action>
Create `pipeline/cache.ts` with these exports:

1. **`EnrichedDeal` interface** — the shape that flows from selector+enricher into the cache:
   - `destination_iata: string`, `destination_name: string`, `price_eur: number`
   - `depart_at: string` (ISO), `return_at: string` (ISO), `booking_url: string`
   - `hotel_estimate_eur: number | null`

2. **`weekKey(date?: Date)` function** — uses `getISOWeek` and `getISOWeekYear` from `date-fns` to produce `"YYYY-WNN"` format (e.g. `"2026-W09"`). Week number MUST be zero-padded to 2 digits with `.toString().padStart(2, '0')`.

3. **`hasCachedDeals(wk: string)` function** — queries `supabase.from('deals_cache').select('id').eq('week_key', wk).limit(1)`. If error, throw. Returns `(data?.length ?? 0) > 0`.

4. **`saveDealsToCache(wk: string, deals: EnrichedDeal[])` function** — maps deals to row objects:
   - `week_key: wk`, `rank: i + 1` (1-indexed)
   - `destination_iata`, `destination_name` from deal
   - `flight_price: deal.price_eur` (NOTE: column is `flight_price`, not `price_eur`)
   - `currency: 'EUR'`
   - `depart_at`, `return_at`, `booking_url` from deal
   - `hotel_estimate: deal.hotel_estimate_eur ?? null` (NOTE: column is `hotel_estimate`, not `hotel_estimate_eur`)
   - `observed_at: new Date().toISOString()`
   - Uses `.upsert(rows, { onConflict: 'week_key,rank', ignoreDuplicates: true })` — NOT insert
   - If error, throw

Import supabase from `../lib/db` (RELATIVE path, NOT `@/lib/db`).
Import `getISOWeek`, `getISOWeekYear` from `date-fns`.

CRITICAL: Column mapping — `deal.price_eur` -> DB column `flight_price`, `deal.hotel_estimate_eur` -> DB column `hotel_estimate`. These names differ between the interface and the schema.
  </action>

  </verify>
