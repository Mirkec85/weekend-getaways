Create `pipeline/send.ts` — the email send script. This mirrors the structure of `pipeline/index.ts` exactly for the env-loading pattern.

**File structure (in this exact order):**

**Section 1: Imports that do NOT touch env vars** (safe to use ES import syntax):
```typescript
import * as fs from 'fs'
import * as path from 'path'
```

**Section 2: Load .env.local** — copy VERBATIM from pipeline/index.ts lines 17-23:
```typescript
const envPath = path.resolve(__dirname, '../.env.local')
if (fs.existsSync(envPath)) {
  for (const line of fs.readFileSync(envPath, 'utf8').split('\n')) {
    const match = line.match(/^([^#=\s]+)\s*=\s*(.*)$/)
    if (match) process.env[match[1]] = match[2].trim()
  }
}
```

**Section 3: require() pipeline modules** (MUST be require, not import — TypeScript hoists imports above env loading):
```typescript
/* eslint-disable @typescript-eslint/no-require-imports */
const { weekKey } = require('./cache') as typeof import('./cache')
const { supabase } = require('../lib/db') as typeof import('../lib/db')
/* eslint-enable @typescript-eslint/no-require-imports */
```

**Section 4: ES imports for non-env-dependent modules** (React Email utilities, React — these don't read env at module load time):
```typescript
import { render, toPlainText } from '@react-email/render'
import React from 'react'
import WeeklyDeals from './emails/WeeklyDeals'
import type { DealCard } from './emails/WeeklyDeals'
import { Resend } from 'resend'
import { format } from 'date-fns'
```

**CRITICAL ordering: The ES imports above will be hoisted by TypeScript. That is OK because `@react-email/render`, `react`, `resend`, and `date-fns` do NOT read `process.env` at module load time. Only `./cache` and `../lib/db` read env vars at load time and MUST use require().**

**Section 5: Helper functions:**

`addUtmParams(url: string, destination: string): string` — Uses `new URL(url)` + `searchParams.set()` to append:
- utm_source: 'weekend-getaways'
- utm_medium: 'email'
- utm_campaign: `weekly-${weekKey()}`
- utm_content: destination lowercased, spaces replaced with hyphens
Returns `u.toString()`. CRITICAL: Do NOT use string concatenation — Kiwi deep_link URLs already have query params.

`formatObservedCET(observed_at: string): string` — Takes the `observed_at` ISO string from deals_cache, converts to CET (UTC+1) by adding 3600000ms to the UTC timestamp, then formats with date-fns: `format(cetDate, "EEE dd MMM HH:mm") + ' CET'`. This produces "Thu 19 Feb 08:12 CET" per EMAIL-02.

`formatDateLabel(isoDate: string): string` — Takes depart_at or return_at ISO string, formats as "Fri 21 Feb" using `format(new Date(isoDate), "EEE dd MMM")`.

**Section 6: main() async function:**

Step 1 — Validate env:
- Check `RESEND_API_KEY` exists, throw if missing
- Read `RESEND_FROM_ADDRESS`, default to `'onboarding@resend.dev'` if not set
- Initialize Resend client: `const resend = new Resend(process.env.RESEND_API_KEY)`

Step 2 — Load deals from deals_cache:
```typescript
const key = weekKey()
const { data: deals, error: dealsErr } = await supabase
  .from('deals_cache')
  .select('*')
  .eq('week_key', key)
  .order('rank', { ascending: true })
```
If error, throw. If no deals, log "No deals cached for {key}. Run pipeline/index.ts first." and `process.exit(1)`.

Step 3 — Load blurbs:
```typescript
const blurbs: Record<string, string> = require('../data/blurbs.json')
```

Step 4 — Build DealCard[] props from deals_cache rows:
Map each deal row to a DealCard:
- destinationName: deal.destination_name
- flightPriceEur: deal.flight_price
- departLabel: formatDateLabel(deal.depart_at)
- returnLabel: formatDateLabel(deal.return_at)
- blurb: blurbs[deal.destination_iata] ?? 'A perfect weekend escape from Zagreb.'
- hotelEstimateEur: deal.hotel_estimate ?? 80
- observedLabel: formatObservedCET(deal.observed_at)
- bookingUrl: addUtmParams(deal.booking_url, deal.destination_name)

Step 5 — Build weekLabel:
Format from first deal's depart_at and last deal's return_at: "Weekend of {dd}-{dd} {Mon} {yyyy}" e.g. "Weekend of 21-23 Feb 2026". Use date-fns format.

Step 6 — Render HTML + plain text:
```typescript
const html = await render(React.createElement(WeeklyDeals, { deals: dealCards, weekLabel }))
const text = toPlainText(html)
```
CRITICAL: `render()` is ASYNC — must await. `toPlainText()` is synchronous — takes the HTML string.

Step 7 — Fetch active subscribers (include unsubscribe_token for per-subscriber footer link):
```typescript
const { data: subscribers, error: subErr } = await supabase
  .from('subscribers')
  .select('id, email, unsubscribe_token')
  .eq('status', 'active')
```
If error, throw. If no subscribers, log and return.

Step 8 — Filter out already-sent (send_log pre-check):
```typescript
const { data: alreadySent } = await supabase
  .from('send_log')
  .select('subscriber_id')
  .eq('week_key', key)
const sentIds = new Set((alreadySent ?? []).map(r => r.subscriber_id))
const pending = subscribers.filter(s => !sentIds.has(s.id))
```
If no pending, log "All subscribers already received this week." and return.

Step 9 — Batch send via Resend (max 100 per call):

CRITICAL: Render is done INSIDE the subscriber loop so each subscriber gets a personalised
unsubscribeUrl in the email footer. HTML/text are re-rendered per subscriber (fast, ~10ms each).

```typescript
const BATCH_SIZE = 100
const fromAddress = process.env.RESEND_FROM_ADDRESS || 'onboarding@resend.dev'
const baseUrl = process.env.NEXT_PUBLIC_BASE_URL ?? 'https://your-domain.vercel.app'
const subject = `Weekend deals - ${weekLabel}`

for (let i = 0; i < pending.length; i += BATCH_SIZE) {
  const chunk = pending.slice(i, i + BATCH_SIZE)

  // Build per-subscriber email payloads (each gets their own unsubscribe URL)
  const batchPayload = await Promise.all(chunk.map(async sub => {
    const unsubscribeUrl = `${baseUrl}/api/unsubscribe?token=${sub.unsubscribe_token}`
    const html = await render(
      React.createElement(WeeklyDeals, { deals: dealCards, weekLabel, unsubscribeUrl })
    )
    const text = toPlainText(html)
    return {
      from: `Weekend Getaways <${fromAddress}>`,
      to: sub.email,
      subject,
      html,
      text,
    }
  }))

  const idempotencyKey = `weekly-send/${key}/batch-${Math.floor(i / BATCH_SIZE)}`
  const { data: batchData, error: sendErr } = await resend.batch.send(batchPayload, { idempotencyKey })

  if (sendErr) {
    // Log failures to send_log for operator visibility, then rethrow
    await supabase.from('send_log').upsert(
      chunk.map(sub => ({
        subscriber_id: sub.id,
        week_key: key,
        status: 'failed',
        provider_message_id: null,
      })),
      { onConflict: 'subscriber_id,week_key', ignoreDuplicates: true }
    )
    throw sendErr
  }
```

Step 10 — Upsert send_log (idempotent):
After each successful batch, upsert into send_log:
```typescript
  const ids = batchData?.data ?? []
  await supabase.from('send_log').upsert(
    chunk.map((sub, idx) => ({
      subscriber_id: sub.id,
      week_key: key,
      status: 'sent',
      provider_message_id: ids[idx]?.id ?? null,
    })),
    { onConflict: 'subscriber_id,week_key', ignoreDuplicates: true }
  )
}
```
CRITICAL: Use `upsert()` with `onConflict: 'subscriber_id,week_key'` and `ignoreDuplicates: true` — NOT insert(). Insert would fail on retry. This matches the pattern in cache.ts.
CRITICAL: `sub.unsubscribe_token` is available because Step 7 selects it from subscribers table.

Step 11 — Log summary:
```typescript
console.log(`Sent ${pending.length} email(s) for ${key}.`)
```

**Section 7: main() invocation:**
```typescript
main().catch((err) => {
  console.error('Send failed:', err)
  process.exit(1)
})
```

**Anti-patterns to avoid:**
- Do NOT use `import` for `./cache` or `../lib/db` — will break env loading (TypeScript hoists imports)
- Do NOT use `@/` path aliases — not available in pipeline context
- Do NOT use string concatenation for UTM params — use `new URL()` + `searchParams.set()`
- Do NOT use `insert()` for send_log — use `upsert()` for idempotency
- Do NOT pass JSX `react:` prop to Resend — pre-render to HTML string with `render()`
- Do NOT forget to `await render()` — it returns a Promise
