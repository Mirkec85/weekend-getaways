  <files>pipeline/emails/WeeklyDeals.tsx</files>
  <action>
Create `pipeline/emails/WeeklyDeals.tsx` — a React Email component that renders the weekly deals newsletter.

**Interface:** The component accepts a single props object:

```typescript
interface WeeklyDealsProps {
  deals: DealCard[]
  weekLabel: string           // e.g. "Weekend of 21-23 Feb 2026"
  unsubscribeUrl?: string     // footer link
}

interface DealCard {
  destinationName: string
  flightPriceEur: number
  departLabel: string         // e.g. "Fri 21 Feb"
  returnLabel: string         // e.g. "Sun 23 Feb"
  blurb: string               // from blurbs.json
  hotelEstimateEur: number    // from hotel-estimates or default 80
  observedLabel: string       // e.g. "Thu 19 Feb 08:12 CET" (EMAIL-02)
  bookingUrl: string          // already has UTM params appended
}
```

Export `DealCard` and `WeeklyDealsProps` as named type exports. Export the component as `default`.

**Layout requirements (EMAIL-01, EMAIL-03):**
- Use `@react-email/components` imports: Html, Head, Body, Preview, Container, Section, Text, Heading, Hr, Link
- ALL styles must be inline `style={{ }}` objects — NO className, NO external CSS (Gmail strips class-based CSS)
- Single-column layout: Container maxWidth 600px, centered. This IS the mobile optimization — Gmail strips media queries, so single column at 600px is the only safe approach.
- Body background: light gray (#f6f9fc), Container background: white (#ffffff), 24px padding

**Deal card structure (for each deal in `deals` array):**
- Section with light background (#f8f8f8), 16px padding, 8px border-radius, 24px margin-bottom
- Heading (h2): destination name, 20px, dark color (#1a1a1a)
- Text: "Flight from EUR {flightPriceEur}" — 24px, bold, accent color (#0070f3)
- Text: "{departLabel} -> {returnLabel}" — 14px, #444444
- Text: blurb — 14px, #333333, 8px vertical margin
- Text: "Hotel est. ~EUR {hotelEstimateEur}/night" — 14px, #444444
- Text: "Observed: {observedLabel}" — 12px, #999999 (EMAIL-02)
- Link: "Book now ->" pointing to bookingUrl — inline-block, blue background (#0070f3), white text, 12px 24px padding, 6px border-radius, bold, no underline

**Header:**
- Heading (h1): "Weekend Getaways" with plane emoji — 24px, #1a1a1a
- Text: weekLabel subtitle — 14px, #666666
- Hr divider

**Footer:**
- Hr divider
- Text: "You're receiving this because you subscribed to Weekend Getaways." — 12px, #999999, center-aligned
- If unsubscribeUrl provided: Link "Unsubscribe" — 12px, #999999

**Preview text:** "Weekend deals from Zagreb - from EUR {deals[0]?.flightPriceEur}" (shows in inbox before opening)

CRITICAL: Use `style={{ }}` prop on every element. Never use className. Use `as const` on textAlign values to satisfy TypeScript.

CRITICAL: Do NOT use async components or fetch() inside the template — all data comes via props. React Email renders with react-dom server rendering, not React Server Components.
