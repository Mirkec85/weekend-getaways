Create `.github/workflows/keepalive.yml` with this exact structure:

```yaml
name: Keepalive

on:
  schedule:
    - cron: '0 12 1 * *'   # 1st of each month at 12:00 UTC
  workflow_dispatch: {}

jobs:
  keepalive:
    runs-on: ubuntu-latest
    permissions:
      actions: write
    steps:
      - uses: actions/checkout@v4
      - uses: gautamkrishnar/keepalive-workflow@v2
```

Key details:
- `permissions: actions: write` is REQUIRED — the keepalive action uses the GitHub API to register activity, which needs write access to the actions scope.
- Monthly schedule is sufficient — the 60-day inactivity threshold is reset each time.
- `workflow_dispatch: {}` included for manual testing.
- No secrets or env vars needed — the action uses the automatic GITHUB_TOKEN.
