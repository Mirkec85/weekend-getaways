  <action>
Create the shared Supabase client and the complete environment variable template.

1. Create `lib/db.ts`:
   ```ts
   import { createClient } from '@supabase/supabase-js'

   const supabaseUrl = process.env.SUPABASE_URL
   const supabaseServiceRoleKey = process.env.SUPABASE_SERVICE_ROLE_KEY

   if (!supabaseUrl) throw new Error('Missing env var: SUPABASE_URL')
   if (!supabaseServiceRoleKey) throw new Error('Missing env var: SUPABASE_SERVICE_ROLE_KEY')

   // Single shared client using the service role key.
   // Used by: Next.js API routes (server-side only) and the /pipeline script.
   // NEVER import this in client components — service role key must stay server-side.
   export const supabase = createClient(supabaseUrl, supabaseServiceRoleKey, {
     auth: {
       persistSession: false,
       autoRefreshToken: false,
     },
   })
   ```

   Note: We use the service_role key (not anon key) for all server-side operations. The anon key is only needed if we add Supabase Auth UI in the future (out of scope for MVP).

2. Create `.env.example` with ALL env vars needed across all five phases. This is the canonical list — engineers (and Claude) refer here when setting up:
   ```bash
   # ─── Supabase ───────────────────────────────────────────────────────────────
   # Project URL from Supabase Dashboard → Project Settings → API
   SUPABASE_URL=https://[project-ref].supabase.co

   # Anon key — safe to expose client-side (used by Next.js public pages if needed)
   SUPABASE_ANON_KEY=eyJ...

   # Service role key — SECRET, never expose client-side
   # Used by: Next.js API routes (server), pipeline script
   SUPABASE_SERVICE_ROLE_KEY=eyJ...

   # ─── Resend ─────────────────────────────────────────────────────────────────
   # API key from Resend Dashboard → API Keys
   RESEND_API_KEY=re_...

   # From address — must match your verified sending domain in Resend
   # e.g. deals@mail.yourdomain.com
   RESEND_FROM=deals@mail.yourdomain.com

   # ─── App ────────────────────────────────────────────────────────────────────
   # Your production URL (used for unsubscribe links, etc.)
   NEXT_PUBLIC_APP_URL=https://yourdomain.com

   # ─── Pipeline (Phase 3+) ────────────────────────────────────────────────────
   # Kiwi Tequila API key — added in Phase 3
   KIWI_API_KEY=

   # ─── Scheduling (Phase 5+) ──────────────────────────────────────────────────
   # Healthchecks.io ping URL — added in Phase 5
   HEALTHCHECKS_PING_URL=

   # Kill switch — set to "true" to skip the next automated send
   PIPELINE_KILL_SWITCH=false
   ```

3. Ensure `.env.local` is in .gitignore (verified in Task 1, confirm here). Do NOT create .env.local — that contains real secrets and is created manually by the developer after Supabase and Resend are set up.
